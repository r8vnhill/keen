# onParentSelectionStart

[common]\
abstract fun [onParentSelectionStart](on-parent-selection-start.md)(state: [S](index.md))

Called at the start of the parent selection process.

The `onParentSelectionStart` method is invoked when the parent selection phase begins. This provides an opportunity to execute any setup or logging before parents are selected from the population.

#### Parameters

common

| | |
|---|---|
| state | The current evolutionary state at the start of the parent selection process. |
