# onEvaluationStart

[common]\
abstract fun [onEvaluationStart](on-evaluation-start.md)(state: [S](index.md))

Called when the evaluation process starts.

This method is triggered at the beginning of the evaluation phase, providing an opportunity to perform preparatory tasks or logging before the evaluation of the population takes place.

common

|---|---|
