# onEvaluationEnd

[common]\
abstract fun [onEvaluationEnd](on-evaluation-end.md)(state: [S](index.md))

Called when the evaluation process ends.

This method is triggered at the end of the evaluation phase, allowing post-evaluation tasks such as logging, analysis of the population, or other actions that need to occur after individuals have been evaluated.

#### Parameters

common

| | |
|---|---|
