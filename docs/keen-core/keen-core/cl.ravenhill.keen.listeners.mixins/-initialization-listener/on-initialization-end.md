# onInitializationEnd

[common]\
abstract fun [onInitializationEnd](on-initialization-end.md)(state: [S](index.md))

Called when the initialization process ends.

This method is invoked at the end of the initialization phase of an evolutionary algorithm. It can be used to perform actions such as final validation, resource cleanup, or logging the results of the initialization.

#### Parameters

common

| | |
|---|---|
