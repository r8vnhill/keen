# onInitializationStart

[common]\
abstract fun [onInitializationStart](on-initialization-start.md)(state: [S](index.md))

Called when the initialization process starts.

This method is invoked at the beginning of the initialization phase of an evolutionary algorithm. It can be used to perform actions such as logging, setting up necessary resources, or conducting pre-initialization checks.

#### Parameters

common

| | |
|---|---|
