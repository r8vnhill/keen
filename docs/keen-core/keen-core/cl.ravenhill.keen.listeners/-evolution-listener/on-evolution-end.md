# onEvolutionEnd

[common]\
abstract fun [onEvolutionEnd](on-evolution-end.md)(state: [S](index.md))

Called at the end of the evolutionary process.

This method is invoked after the evolutionary algorithm has completed its process. It receives the final state of the evolution, which can be used for final logging, cleanup, or other post-evolution tasks.
