# display

[common]\
open suspend fun [display](display.md)()

Displays the listener's state.

This method outputs the result of the `toString` method to the console. Implementing classes should override this method to provide a custom display format for the listener's state. This could be through a formatted string, a graphical representation, or any other suitable output.
