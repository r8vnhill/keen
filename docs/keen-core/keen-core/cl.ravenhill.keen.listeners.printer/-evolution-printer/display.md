# display

[common]\
open suspend override fun [display](display.md)()

Displays the evolution details.

This method prints out the statistics of the evolutionary process, including generation times, fitness metrics, and the fittest individual. It is invoked periodically based on the [every](../../../../keen-core/cl.ravenhill.keen.listeners.printer/-evolution-printer/every.md) interval.
