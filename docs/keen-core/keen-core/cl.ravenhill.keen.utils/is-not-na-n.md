# isNotNaN

[common]\
fun [Double](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-double/index.html).[isNotNaN](is-not-na-n.md)(): [Boolean](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-boolean/index.html)

Checks if a [Double](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-double/index.html) value is not NaN (Not a Number).

This extension function provides a convenient way to verify that a [Double](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-double/index.html) value is a valid number and not the special NaN (Not a Number) value. NaN is used to represent undefined or unrepresentable values in floating-point calculations.

#### Return

`true` if the [Double](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-double/index.html) value is not NaN, `false` if it is NaN.
