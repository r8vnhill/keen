# mutate

[common]\
open fun [mutate](mutate.md)(random: [Random](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.random/-random/index.html) = Domain.random): [G](index.md)

Mutates the gene by generating a new value using the `generator` function.

The `mutate` function creates a new instance of the gene with a value generated by the `generator` function. This method introduces genetic variability, which is essential for the evolutionary process. The mutation can be influenced by the provided `Random` instance, allowing for controlled randomness in tests or specific scenarios.

### Example:

```kotlin
val gene = IntGene(42)
val mutatedGene = gene.mutate()
println(mutatedGene.value) // Output: A new random value generated by the `generator` function
```

#### Return

A new gene instance with the mutated value.

#### Parameters

common

| | |
|---|---|
| random | The `Random` instance used to generate the new value. Defaults to the global `Domain.random`. |
