# Gene

interface [Gene](index.md)&lt;[T](index.md), [G](index.md) : [Gene](index.md)&lt;[T](index.md), [G](index.md)&gt;&gt; : [Feature](../../../../keen-core/keen-core/cl.ravenhill.keen.repr/-feature/index.md)&lt;[T](index.md), [G](index.md)&gt; 

Represents a gene in an evolutionary algorithm.

The `Gene` interface extends the [Feature](../../../../keen-core/keen-core/cl.ravenhill.keen.repr/-feature/index.md) interface, adding functionality specific to genetic algorithms, such as mutation and value generation. A gene is a fundamental unit within a genetic structure (such as a chromosome) and typically represents a single piece of genetic information. This interface defines the core operations that a gene must support, including mutating its value for easier processing within evolutionary algorithms.

## Usage:

Implement this interface to create specific types of genes that can be used in genetic algorithms. Each gene should define how its value is generated and how it mutates. The `mutate` function is particularly important for introducing variability into the population during the evolutionary process.

### Example 1: Implementing an Integer Gene

```kotlin
data class IntGene(override val value: Int) : Gene<Int, IntGene> {
    override val generator: (Random) -> Int = { random -> random.nextInt(0, 100) }

    override fun copyWithValue(value: Int) = IntGene(value)
    // ... Other gene-specific methods and properties ...
}
```

### Example 2: Mutating a Gene

```kotlin
val gene = IntGene(42)
val mutatedGene = gene.mutate()
println(mutatedGene.value) // Output: A new random value generated by the `generator` function
```

### Example 3: Converting a Gene to a List

```kotlin
val gene = IntGene(42)
val listWithValue = gene.toList()
println(listWithValue) // Output: [42]
```
