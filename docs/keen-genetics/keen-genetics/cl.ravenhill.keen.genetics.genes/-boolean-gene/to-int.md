# toInt

[common]\
open fun [toInt](to-int.md)(): [Int](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin/-int/index.html)

Converts the boolean gene's value to an integer.

This method returns `1` if the gene's value is [True](-true/index.md) and `0` if it is [False](-false/index.md). It provides a convenient way to work with the gene's value in contexts where integers are required.

#### Return

`1` if the gene's value is `True`, `0` if it is `False`.
