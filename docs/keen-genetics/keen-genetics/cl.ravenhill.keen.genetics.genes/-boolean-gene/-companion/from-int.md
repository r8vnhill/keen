Converts an integer value into a `BooleanGene`.

This function converts an integer (where `1` represents `True` and `0` represents `False`) into a `BooleanGene` instance. It is useful for working with external data sources that represent booleans as integers.

#### Return

A `BooleanGene` instance representing the boolean equivalent of the provided integer.
