Checks if the chromosome contains all the specified genes.

The `containsAll` method verifies whether all genes in the provided collection are present in the chromosome. This is useful for checking if a specific set of genes exists in the chromosome.

#### Return

`true` if the chromosome contains all the specified genes, `false` otherwise.
